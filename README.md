# GitHub Analytics Dashboard

🚀 Live Demo: https://github-analytics-dashboard-three.vercel.app

A modern GitHub Analytics Dashboard built with Next.js, TypeScript, GitHub API, Recharts, and Framer Motion.
## Features

- GitHub Profile Analysis
- Repository Statistics
- Language Distribution Chart
- Contribution Activity Calendar
- Top Repositories by Stars
- Total Stars & Forks Analytics
- Responsive Modern UI
- Interactive Charts and Visualizations
- Real-time GitHub Data Fetching

## Tech Stack

- Next.js 16
- TypeScript
- React
- GitHub REST API
- Recharts
- Framer Motion
- React GitHub Calendar

## Installation

```bash
git clone <repository-url>
cd github-analytics-dashboard
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Usage

1. Enter any GitHub username.
2. Click Analyze.
3. View profile insights, repositories, languages, stars, forks, and contribution activity.
